# Code of Conduct

This project follows a simple standard: be useful, respectful, and specific.

## Expected Behavior

- Be direct without being hostile.
- Assume good intent, but prioritize user safety and export correctness.
- Keep reports actionable.
- Do not pressure maintainers or users to share private chat exports.

## Unacceptable Behavior

- Harassment, insults, or discriminatory language.
- Posting secrets, private transcripts, or personal data from someone else's export.
- Social engineering maintainers or users for tokens, cookies, session files, or private Codex state.

## Reporting

For normal conduct issues, open a GitHub issue with relevant context.

For anything involving secrets, private exports, or security-sensitive material, use the security reporting path in `SECURITY.md`.
