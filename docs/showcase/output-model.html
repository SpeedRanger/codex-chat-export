chat.md anatomy

What humans see

The Markdown file is a chronological transcript. Each Codex event becomes a clear section with a timestamp.

User

The prompt or instruction that started a turn.

Reasoning Summary

Persisted summary blocks when Codex stores them.

Commentary

Status updates Codex sent while working.

Tool Call

Structured command/tool arguments rendered as JSON.

Tool Output

Captured output from terminal/tools in fenced text blocks.

Assistant

The final response or explanation returned to the user.

chat.json + manifest

What tools see

JSON keeps the structured export document and raw rollout lines. Manifest keeps the bundle inventory lightweight.

chat.md is the story.

Best for reading, sharing snippets, reviewing decisions, and understanding what happened.

chat.json is the evidence.

Best for downstream tooling, audits, search, importers, and lossless reprocessing.

manifest.json is the label.

Best for metadata, file inventory, stats, and future bundle compatibility.
